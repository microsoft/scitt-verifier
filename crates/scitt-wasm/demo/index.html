Trust anchors

Trusted roots are CAs you already trust; the signer's chain must lead to one of them. Without them the chain is checked only against the root the statement carries, which proves consistency, not identity. Service certificate is the ledger's TLS certificate, from its identity service; only the key it vouches for is used to check receipts, so a key set that arrived through a proxy cannot add keys of its own.

You declare how the artifact relates to the statement; it is never inferred. payload-bytes says the payload is the artifact. payload-digest says it is a digest of it (RFC 9995 hash envelope). Choosing for you would report a relationship you never asserted — so a mode that does not fit says so rather than guessing.

Decode a claim

        

          Producers embed whole documents — a security policy, an SBOM — as
          encoded strings. Name the claim and its encoding; nothing is decoded that
          you did not ask for, and no encoding is guessed. The digest is over the
          exact decoded bytes, so it compares directly with one a producer
          publishes. Decoding is not verification: these bytes are only as
          trustworthy as the verdict above.
